# Dataset record

## Composition

| Class or role | PDFs |
| --- | ---: |
| Injected | 9,774 |
| Benign original or matched benign confounder | 19,548 |
| **Total** | **29,322** |
| Base documents | 4,983 |

Benign source documents were generated by [PDFAutoGen](https://github.com/volkthienpreecha/PDFAutoGen). It uses seeded generation, fourteen templates, structured JSON content banks, and controlled layout variation. It does not use an LLM to write document content.

## Frozen splits

Splits are grouped by `base_pdf_id`. A base document and its related benign, confounder, and injected variants cannot cross split boundaries.

| Split | PDFs | Share |
| --- | ---: | ---: |
| Train | 23,766 | 81.05% |
| Validation | 2,637 | 8.99% |
| Test | 2,919 | 9.95% |
| **Total** | **29,322** | **100%** |

The exact group assignments are in [`reproducibility/frozen-splits.json`](reproducibility/frozen-splits.json).

The test set contains 973 injected PDFs and 1,946 negatives. The balanced paired subset contains 973 injected PDFs and 973 matched benign confounders.

## Triplet structure

A benchmark triplet contains:

| Role | Label | Meaning |
| --- | ---: | --- |
| `benign_original` | 0 | Untouched benign source PDF. |
| `benign_confounder` | 0 | Benign variant designed to share non-label provenance or layout signals with the injected member. |
| `injected_attack` | 1 | PDF containing the controlled hidden instruction. |

Rows are linked through `triad_id`, `sample_id`, and `base_pdf_id`.

## Core schema

The paper corpus records:

- stable identifiers: `pdf_id`, `sample_id`, `base_pdf_id`, `pair_id`, `triad_id`;
- split and provenance: `dataset_split`, `split_group`, `freeze_version`, `seed`;
- source metadata: `source_document_id`, `source_original_filename`;
- labels and roles: `label`, `pdf_role`;
- attack metadata: `message_type`, `attack_family`, `attack_strength`;
- PDF regimes: `spatial_regime`, `rendering_regime`, `structural_regime`;
- matched controls: `benign_confounder_family`; and
- corpus-relative file paths.

Identifiers, labels, file paths, attack names, and regime fields are bookkeeping metadata. They are not valid detector features.

## Example triplets

[`examples/triplets.jsonl`](examples/triplets.jsonl) contains fifteen exact triplet records:

- five train triplets;
- five validation triplets; and
- five test triplets.

The examples preserve the original IDs, split assignments, regimes, confounder families, and corpus-relative paths. The PDF binaries were not present in the recovered paper artifact and are not included.

## Availability

The complete 29,322-PDF dataset is published at [Hugging Face](https://huggingface.co/datasets/volkthienpreecha/crackedpdfs) and archived at [Zenodo DOI `10.5281/zenodo.21735803`](https://doi.org/10.5281/zenodo.21735803). The paper release is pinned at [dataset revision `245bc98`](https://huggingface.co/datasets/volkthienpreecha/crackedpdfs/tree/245bc98ec7e838346ee6fd5bdf5fed1b16d2a3e5). It includes the PDF binaries, complete row-level metadata, frozen feature and label tables, the paper evaluation split, and publication metrics.

The fast reproduction manifest pins downloads to immutable dataset revision `02d7e0be03b09d6a29c7e4d388440bc1f5a4907b`. Run `make reproduce-results` from the repository root to verify the downloaded hashes and regenerate the hard-setting result table.

The `dataset_split` column in `metadata.parquet` and `labels.parquet` preserves the generation-layer assignment recorded in the original publication table. The paper's model evaluation used `data/splits.json`, whose counts are the 23,766 / 2,637 / 2,919 split shown above. Use `splits.json` for reproducing paper results.

## Known issues

The [2026-09 erratum](ERRATA.md) documents these issues in this corpus. No file or label changes:

- `spatial_regime` and the other regime fields record the requested placement. Realized placement is `straddles_page_edge` for every label except `extreme_off_page`, with most injected glyphs below the page.
- Every injected PDF contains `DATASET_SAMPLE_ID` and `MESSAGE_TYPE=` and no confounder does; `SYSTEM_POLICY_DO_NOT_REMOVE` and `DOCUMENT_LAYOUT_NOTE` are also role-specific. Strip them before scoring a detector on raw text.
- Injected payloads are longer than their confounders in 8,849 of 8,982 non-acrostic pairs, so payload length is a paired-ranking shortcut.
- `in_page_split_text_objects` has no `strong` samples.

## Limitations

The corpus uses synthetic, one-page benign documents and controlled injection generators. It does not represent arbitrary real-world PDFs, scanned documents, OCR-only ingestion, adaptive attacks, all parser implementations, or all hidden-document attack families.
